# Vajna Gépészet — weboldal

Statikus, build nélküli egyoldalas weboldal (GitHub Pages).

- `index.html` — az oldal
- `css/style.css` — a teljes design rendszer (tokenek a `:root`-ban)
- `js/main.js` — menü, finom belépés, űrlap (mailto)
- `jogi/` — impresszum, adatkezelési tájékoztató (a `[kitöltendő]` mezők pótlandók)

Fotók: az oldal szándékosan nem használ képet. A „Referenciafotó helye” keretekbe
valódi ügyfélfotó kerül (`<img src="..." alt="...">` a `.slot-frame` elembe).

Weboldal: [DAEKON](https://daekon.hu)
